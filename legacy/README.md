## MicroPython で Pico 2 を使う際の注意

これらのスクリプトが前提としていた結線（`scl=Pin(4), sda=Pin(5)`）は、RP2350 では
`ValueError: bad SCL pin` で拒否されます。RP2350 の I2C0 は **GP4 = SDA、GP5 = SCL** です。
正しい結線での動作確認は MicroPython の raw REPL 経由で行い、その過程で実センサーの
校正データと ADC 値を取得して、C++ 実装の検証基準としました。
